# shliapuzhnikov-og

OG-превью (og:image) и страницы-превью для мессенджеров сайта [shliapuzhnikov.com](https://shliapuzhnikov.com).
Лежат здесь, потому что краулеры Telegram и Meta не могут скачивать картинки с сервера в РФ.
Файлы генерируются автоматически командой `npm run og` в основном репозитории - руками не править.
